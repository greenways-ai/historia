title: Agent skill
description: Give coding agents deterministic access to repository provenance.
---

The portable `greenways-historian-agent` skill teaches Codex, Kimi, and other agents how to initialize, update, query, and report provenance from the local SQLite index.

Install the [skill directory](https://github.com/greenways-ai/historian/tree/main/skills/greenways-historian-agent) at user or project scope, then begin a new agent session.
