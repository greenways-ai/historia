Historia for ChatGPT privacy

User-controlled and metadata-only. The companion does not scrape ChatGPT conversations. It saves a normalized conversation URL and page title only after you explicitly choose to bookmark the active tab. Full history enters Historia through an official ChatGPT export that you select yourself.

Browser companion data

The extension may store:

  • normalized https://chatgpt.com/c/<id> or /share/<id> links;
  • the active tab title when a bookmark is explicitly saved;
  • bookmark notes and tags entered by you;
  • prompt or context templates entered by you;
  • record timestamps and deletion tombstones used for deterministic sync.

Query strings and fragments are removed from saved ChatGPT links. The extension does not run a content script on ChatGPT pages.

What the extension does not read

  • conversation message text or generated answers;
  • browser cookies, ChatGPT access tokens, authorization headers, passwords, or browser storage credentials;
  • private or undocumented ChatGPT APIs;
  • other page DOM content, attachments, or hidden account history;
  • other websites or background browsing history.

Official history import

For full conversation history, request the official ChatGPT data export and choose the resulting ZIP, extracted directory, or conversations.json in the local Historia application. Import is an explicit local operation. The authoritative archive is a Git vault on your computer, with a rebuildable SQLite projection for search and bounded context retrieval.

Local native host

The extension may use browser native messaging to ask ai.greenways.historia_collect for local status and to open the local Historia application. It does not send page content through that connection. Historia configures no remote Git repository by default and operates no collection cloud or analytics service.

Browser metadata sync

Browser sync is disabled by default. When enabled, only the bounded companion state—bookmarks, prompt templates, tags, notes, timestamps, and deletion tombstones—is written to the browser's sync storage. Conversation bodies, ChatGPT export files, Historia Git objects, local search indexes, credentials, and private keys are excluded.

A portable JSON sync bundle can be downloaded and merged manually. Conflict resolution is deterministic: the record with the latest canonical update timestamp wins, and deletions are retained as tombstones.

Prompt handoff

The companion can copy a saved prompt and open ChatGPT. It never inserts text into the page or sends a prompt automatically. You remain responsible for reviewing and submitting copied material.

Retention and deletion

Removing a bookmark or prompt creates a sync tombstone so the deletion propagates to opted-in browser profiles. Disabling sync stops future browser-sync writes. Uninstalling the extension does not delete the separate local Historia vault.

Git history is intentionally durable. Historia distinguishes hiding content, creating a redacted derived view, and a deliberate purge that rewrites relevant refs and must also be repeated for every remote or clone.

Firefox data category

Firefox classifies the explicit active-tab URL/title lookup under browsingActivity. The extension does not request personalCommunications or websiteContent collection because it does not read conversation messages or page content.
