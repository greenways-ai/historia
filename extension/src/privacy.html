Historia Collect privacy

Local by design. Historia Collect sends explicitly captured ChatGPT page content only to the Historia native host installed on this computer. It does not send conversation data to Greenways or another remote service.

What collection includes

When you choose Collect this conversation, or enable automatic collection, the extension reads the conversation currently rendered in the permitted ChatGPT tab. The local observation can include:

  • visible user and assistant message text;
  • visible code blocks and basic formatting;
  • visible image or file references and available display metadata;
  • message roles, ordering, parent relationships, and the active conversation path;
  • the current ChatGPT page origin, path, and title;
  • the private local source label configured for this browser profile.

URL query strings and fragments are removed before archival.

Where data goes

The extension transmits the bounded observation through browser native messaging to ai.greenways.historia_collect, a local executable registered for the Historia Collect extension identity. The host validates the observation and writes it into your local Git-native Historia vault. A local SQLite index may be rebuilt from that vault for search and context retrieval.

Historia configures no remote Git repository by default. Syncing or publishing a vault is a separate user-controlled Git operation.

What Historia Collect does not read

  • browser cookies;
  • ChatGPT access tokens or authentication headers;
  • passwords;
  • browser local-storage or session-storage credentials;
  • other tabs or websites outside the declared ChatGPT origins;
  • unrendered account history through undocumented provider APIs.

What Historia Collect does not operate

The extension contains no analytics, advertising, telemetry, cloud upload, remote model call, or third-party tracking SDK. The extension's network host permissions are limited to ChatGPT pages so its content script can observe the rendered conversation. Archive writes use the local native-messaging connection.

Manual and automatic collection

Manual collection is the default. Automatic collection is disabled until you enable it in settings. When enabled, it is debounced after rendered messages change. Exact duplicate observations remain idempotent.

Retention and deletion

Git history is intentionally durable. Removing a conversation from the current view does not erase earlier reachable Git objects. Historia distinguishes:

  • hide: exclude content from ordinary retrieval;
  • redact: create a safer derived view while retaining the source record;
  • purge: rewrite affected refs, expire reflogs, run garbage collection, and repeat the operation for every remote or clone.

Uninstalling the browser bridge removes its native-host registration. It does not delete the vault or indexed conversations.

Firefox data categories

Firefox classifies the local native-messaging transfer under browsingActivity, personalCommunications, and websiteContent. These categories describe the current ChatGPT page identity, rendered chat messages, and visible page content transferred to the local Historia host. They do not indicate remote collection by Greenways.
