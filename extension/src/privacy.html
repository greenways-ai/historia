Historia for ChatGPT privacy

User-controlled and local by default. The companion does not scrape ChatGPT conversations. It saves a normalized conversation URL and page title only after you explicitly bookmark the active tab. Full history enters Historia through an official ChatGPT export that you choose, and local history leaves the native host only in response to an explicit search, conversation, context, or sync action.

Browser companion data

The extension may store:

  • normalized https://chatgpt.com/c/<id> or /share/<id> links;
  • the active tab title when a bookmark is explicitly saved;
  • bookmark notes and tags entered by you;
  • prompt or context templates entered by you;
  • record timestamps and deletion tombstones used for deterministic sync;
  • temporary search results or bounded context displayed in the open companion page.

Query strings and fragments are removed from saved ChatGPT links. The extension does not run a content script on ChatGPT pages.

What the extension does not read from ChatGPT

  • conversation message text or generated answers from the rendered ChatGPT page;
  • browser cookies, ChatGPT access tokens, authorization headers, passwords, or browser storage credentials;
  • private or undocumented ChatGPT APIs;
  • other page DOM content, attachments, or hidden account history;
  • other websites or background browsing history.

Official history import

For full conversation history, request the official ChatGPT data export and explicitly provide the resulting ZIP, extracted directory, or conversations.json to Historia. The extension can ask the local native host to import an absolute path that you type; browsers do not reveal that path automatically. The authoritative archive is a Git vault on your computer, with a rebuildable SQLite projection for search and bounded context retrieval.

Local native host

The extension uses browser native messaging to call a closed set of operations on ai.greenways.historia_collect: status, history listing and search, bounded conversation retrieval, official-export import, context construction, and companion-metadata sync. Search and context responses may contain conversation text from your local Historia vault because you explicitly requested it. Responses are bounded below the browser's native-messaging limit and retain Git source-ref and commit provenance.

The extension never sends ChatGPT page content, account cookies, credentials, or private API responses through the native connection. Historia configures no remote Git repository by default and operates no collection cloud or analytics service.

Git-vault metadata sync

You may explicitly pull or push bookmarks, prompt templates, tags, notes, timestamps, and deletion tombstones through the dedicated local Git ref refs/historia/companion/chatgpt. Pushes use the last observed Git head; concurrent device changes are deterministically merged and committed rather than silently overwritten. Conversation bodies already reside in the separate Historia history refs and are not copied into this metadata ref.

Browser metadata sync

Browser sync is disabled by default. When enabled, only the bounded companion state—bookmarks, prompt templates, tags, notes, timestamps, and deletion tombstones—is written to the browser's sync storage. Conversation bodies, ChatGPT export files, Historia Git objects, local search indexes, credentials, and private keys are excluded.

A portable JSON sync bundle can be downloaded and merged manually. Conflict resolution is deterministic: the record with the latest canonical update timestamp wins, and deletions are retained as tombstones.

Prompt and context handoff

The companion can copy a saved prompt or a bounded Historia context bundle and open ChatGPT. It never inserts text into the page or sends a prompt automatically. You remain responsible for reviewing and submitting copied material.

Retention and deletion

Removing a bookmark or prompt creates a sync tombstone so the deletion propagates to opted-in projections. Disabling sync stops future browser-sync writes. Uninstalling the extension does not delete the separate local Historia vault.

Git history is intentionally durable. Historia distinguishes hiding content, creating a redacted derived view, and a deliberate purge that rewrites relevant refs and must also be repeated for every remote or clone.

Firefox data category

Firefox classifies the explicit active-tab URL/title lookup under browsingActivity. The extension does not request personalCommunications or websiteContent collection because it does not read conversation messages or page content from ChatGPT. Content explicitly retrieved from the local Historia native host is local application data, not website extraction.
