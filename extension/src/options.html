Historia for ChatGPT

Metadata only. The browser companion saves chat URLs, page titles, prompt templates, tags, notes, and tombstones. It does not read ChatGPT messages, cookies, authentication data, or undocumented provider endpoints.

History and context

Use ChatGPT's official data export, then import the ZIP or conversations.json through the local Historia application. Historia keeps the authoritative archive in Git and builds a rebuildable local search index.

Data handling

Removing the extension does not delete your local Historia vault. Browser-sync metadata can be disabled here and deleted through the companion's sync bundle workflow or browser account controls.
